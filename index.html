clipper

clipper is a personal publishing tool run by a single independent creator. It takes short video clips the creator has prepared and uploads them to the creator's own accounts on YouTube and TikTok.

It is not a public service. There is no sign-up, and it only ever acts on accounts the creator owns and has connected through YouTube's and TikTok's official sign-in screens.

What it does with each platform:

  • YouTube: uploads Shorts to the creator's channel using the YouTube Data API.
  • TikTok: uploads videos to the creator's account using TikTok's Content Posting API.
